# Football Tactics Board

A free, open, browser-based football (soccer) coaching tool for coaches, parents, and football enthusiasts.

## Features

- **Visual pitch** with FIFA-standard markings
- **Draggable player dots** for both home and away teams, plus a ball
- **Adjustable team sizes** from 5-a-side (U6) to 11-a-side (U14+)
- **Asymmetric teams** for number advantage training (e.g., 10v9, 10v8)
- **Predefined formations** for every age group (1-2-1 through 4-3-3)
- **Player names** assignable via roster editor
- **Save/load** setups via browser localStorage
- **Export as PNG** and share directly to WhatsApp (on mobile)
- **Mobile-first** design with touch drag-and-drop
- **PWA support** - add to home screen for offline use
- **No accounts, no servers** - works entirely in the browser

## Usage

Open `index.html` in any modern browser. No build step or server required.
